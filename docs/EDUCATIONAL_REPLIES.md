### Before ❌ (Sales-focused):
```
User: "Harga emas hari ini berapa?"
Bot: "Harga emas hari ini bisa dicek di update terbaru kami ya! 
     📊 Atau DM untuk info lebih detail."
     ↑ Mengarahkan ke DM/jualan
```

### After ✅ (Education-focused):
```
User: "Harga emas hari ini berapa?"

     Tahukah kamu faktor apa saja yang mempengaruhi harga emas?

     ↑ Edukasi + pertanyaan balik = diskusi
```
